PCB Layout Editor

Written Guide Step-by-Step: Start the PCB Layout and Define Board Layers
01

Update PCB from schematic

Use KiCad's Update PCB from Schematic command to bring the components and their connections into the PCB Editor.

Add screenshot: Update PCB from Schematic
02

Place your components

Move components inside the board area. Group related parts and consider connector access, spacing, and how the connections can be routed.

Tip: Show a bad layout and a good layout side-by-side.
03

Take a look at board setup

Open Board Setup to see where KiCad organises board layers and design rules. Use the layer selector to view front and back copper, silkscreen, solder mask, and Edge.Cuts. Draw each feature on its intended layer.

Add screenshot: Board Setup dialog
04

Draw the board outline

Use the Edge.Cuts layer to draw a closed outline for the PCB shape.

Add screenshot: Board outline on Edge.Cuts
05

Add copper pours and exposed copper

A copper zone can fill an area on a copper layer, often to connect a net across the board. For exposed copper features, check the solder-mask layer settings and clearances so the intended copper remains uncovered.

Add screenshot: Copper zone and solder-mask layers
Lesson checkpoint: Your schematic components are in the PCB Editor, and the board outline and copper features are on their intended layers.
