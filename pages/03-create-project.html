KiCad Overview

One project, several design tools

KiCad projects bring together several different files made with different tools. The main tools you'll use in this workshop, and most often when designing a PCB, are the Schematic Editor, Footprint Editor, Symbol Editor, and PCB Editor .

What is a Schematic?
Add schematic image here

A schematic is a diagram that shows how the electrical parts of a circuit are connected.

In KiCad, the Schematic Editor is where you place components, connect their pins with wires, add labels, power symbols, and organise everything into a circuit that is easy to understand.

The schematic describes the electrical connections in your design. It does not show where components will physically sit on the PCB.

What are Symbols?
Add symbol image here

Symbols are the graphical representations of electrical components that you place in the schematic.

A symbol shows important information about a component, especially its pins and pin numbers, so KiCad knows how that component connects electrically to the rest of the circuit.

KiCad comes with a large library of common symbols for things like resistors, capacitors, ICs, connectors, and microcontrollers.

However, not every component will already exist in KiCad. If you are using a more specific or uncommon part, you may need to:

  • Import a symbol provided by the manufacturer or another library.
  • Create your own symbol using KiCad's Symbol Editor.

The important thing to remember is that a symbol represents the component electrically, not physically.

What are Footprints?
Add footprint image here

A footprint represents the physical shape of a component on the PCB.

It defines things such as:

  • Where the component's pads are located.
  • The size and shape of those pads.
  • The spacing between pins.
  • The component's physical outline.
  • Silkscreen markings and other mechanical information.

For example, a resistor may use the same schematic symbol, but physically it could be a small 0805 SMD resistor or a much larger through-hole resistor. These would use different footprints.

KiCad includes a large library of standard footprints for common packages such as DIP, SOIC, QFN, 0805, 0603, and many others.

Just like symbols, more unusual components may require you to import a footprint or create your own using KiCad's Footprint Editor.

A useful way to remember the difference is:

Symbol = what the component does electrically.

Footprint = what the component looks like physically on the PCB.

What's the PCB Editor?
Add PCB Editor image here

The PCB Editor is where your schematic is turned into the physical layout of the circuit board.

After assigning footprints to your schematic components, you can bring them into the PCB Editor and decide where everything will physically sit.

This is where you can:

  • Position and rotate components.
  • Draw the shape of the PCB.
  • Route copper traces between components.
  • Add copper zones, such as a ground plane.
  • Add mounting holes and other mechanical features.
  • Add silkscreen text, labels, logos, and artwork.
  • Configure PCB layers and design rules.
  • Check whether components and traces fit together correctly.

The PCB Editor is essentially a 2D view of the physical circuit board that will eventually be manufactured.

Your schematic tells KiCad what should be connected, while the PCB Editor determines where everything goes and how those connections are physically routed.

Creating your KiCad Project

Written Guide Step-by-Step: Create a Project

Starting a new project

  1. Open KiCad. You'll see the home screen shown in the overview above.
  2. Click File → New Project.
  3. Select the Default KiCad project template.
  4. Choose where to save your project and give it a name, for example USRC_Keychain.
  5. Click Save.

The Project Files panel on the left will now show three new files: the project file (.kicad_pro), schematic file (.kicad_sch), and PCB file (.kicad_pcb).

Opening the Schematic Editor

Double-click the .kicad_sch file in the Project Files panel, or click Schematic Editor. A blank page will open. This is where we'll build the circuit in the next lesson.

Lesson checkpoint: You've created your KiCad project.
